# Plan de Pruebas de Software (Test Plan)

## 1. Introducción
El objetivo de este plan es coordinar las actividades de verificación del framework integrado de automatización en Python.

## 2. Entorno de Pruebas (Test Environment)
* **URL de Aplicación Web:** [Sauce Demo](https://www.saucedemo.com/)
* **URL de API Base:** [ReqRes API](https://reqres.in/)
* **Navegadores Soportados:** Google Chrome (Modo Incógnito), Microsoft Edge, Mozilla Firefox.

## 3. Herramientas y Frameworks
* **Lenguaje:** Python 3.13
* **Motor Core:** Pytest
* **Librerías Clave:** Selenium WebDriver, Requests, Faker, Pandas.

## 4. Criterios de Entrada y Salida
* **Entrada:** Código del sitio de pruebas disponible, localizadores estables e inmutables.
* **Salida:** Reporte técnico HTML y reporte ejecutivo consolidado en formato Excel sin bloqueantes activos.
